Dates are planning targets, not assertions that a gate has passed.

| T+4 / T+8 / T+12 weeks | Acquisition and service review | Repeat frozen prompt panel; changes logged; judge buyer action separately from citations |

At eight weeks after a stable indexed release: if eligible search appearances are observed, responses to known-positive action prompts remain weak, named head-term action recommendations show no repeatable increase, and qualified brief volume does not improve against the baseline, the acquisition hypothesis is unsupported. Diagnose retrieval first: not indexed/retrieved means distribution failure, not proof of product irrelevance. If retrieved but not recommended, test independently published service evidence and partnerships; if recommended but no buyer action, test scope/value/friction; if briefs arrive but proposals fail, repair supplier fulfilment before more acquisition spending. Do not claim statistical failure where the sample is too small. Record counts and uncertainty.

Current release blockers: supplier response targets/contacts and written attribution commitments; Harry-approved wording; human approval of adjudications and unresolved source evidence; clean logged-out baseline; complete consent/measurement coverage assessment; operational staff intake and pilot acceptance. The joined private project flow is implemented and passes isolated checks, but that is not a completed real supplier transaction. Production remains frozen.
